# 验证记录

日期：2026-10-15，macOS 本机 Apple Silicon，Swift 6.3.2。

## 已通过

- Release 编译并生成可运行的 `.app`，临时签名。
- 8 项几何单元测试：奇数像素三等分无缝衔接、带负坐标的显示器边界、窗口间距与屏幕外边距、竖屏纵向三等分、四角触发优先级、最大重叠显示器选择、跨屏比例迁移与边界限制、居中。
- 通过真实 AX API 调整一个由测试创建的临时窗口：左半屏、右半屏、左上角、右下角、中间三分之一、最大化、居中、恢复，8/8 通过（容差 3 pt）。结果保存在 `smoke-test.json`。此结果来自有权限的终端直接启动；从 Finder 启动的打包应用仍需用户单独开启辅助功能授权。
- 通过原生 UI 自动化验证：命令网格与偏好设置可显示；新增自定义命令；修改宽度为 60%；删除测试命令；快捷键可录制；与右半屏冲突的键位被拒绝并显示中文提示；恢复默认。
- 已视觉阅读三张官方商店截图，第二张为命令网格/快捷键/触发区编辑器，第三张为外观、绿色按钮和间距设置。实现采用相同的主要信息结构，使用中文标签与原生控件。

## 未验证或限制

- 当前仅有单显示器；跨屏和竖屏的坐标计算已测试，实际多屏硬件未测试。
- 自动化向指定应用输入键盘事件不能证明系统级热键分发，未将其计为端到端热键通过。
- 拖拽吸附、拖离恢复、触发区高亮、绿色按钮菜单已实现，但未把代码存在等同于完整交互实测。这些功能需要在最终安装位置授予辅助功能后继续实际操作验证。
- 登录启动未开启，以免改变用户的登录项。
- 未测试或宣称 iCloud 同步；此版本没有实现。
- 未获取 Magnet 二进制；没有可用的 REA 原版二进制证据，也没有声称二进制或行为完全等价。
